# meeshApps

Marka studia dla gier z tego repo: strona www, dokumenty wymagane przez App Store i identyfikacja wizualna.

- [`WYMAGANIA.md`](WYMAGANIA.md): co jest potrzebne do sprzedaży w App Store (strony, DSA, RODO, konto Apple, podatki).
- [`kit.html`](kit.html): podgląd całości: checklista, układ strony, 3 palety, 6 wersji logo, 3 ikonki.
- [`site/`](site/): gotowa statyczna strona PL/EN do wrzucenia na GitHub Pages:
  - `index.html` strona główna, `apps/cieciwa.html` wzór strony gry
  - `privacy.html` polityka prywatności (Privacy Policy URL)
  - `support.html` wsparcie (Support URL)
  - `terms.html` warunki korzystania (uzupełnienie EULA Apple)
  - `legal.html` dane sprzedawcy (DSA)
- [`brand/`](brand/): SVG logo i ikonek w trzech paletach (`ember`, `lagoon`, `grape`), wersje na jasne i ciemne tło.

Pola do uzupełnienia są w plikach oznaczone `<mark class="todo">`.
